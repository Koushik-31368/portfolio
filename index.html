BUILD 03

Aegis — Edge Resilience System

2026
JavaSpring BootPythonRedisResilience4jONNX RuntimePostgreSQLPrometheusGrafanaDocker
  • A distributed IoT telemetry pipeline built to demonstrate production-grade resilience patterns: AI-based anomaly scoring at the edge, circuit-breaker-triggered buffering, rate-limited recovery drain, and idempotent deduplication at the cloud.
  • Edge Gateway scores every reading with an ONNX-exported Isolation Forest model before a Resilience4j-protected forward to the cloud; on failure it pushes into a criticality-aware Redis buffer that evicts the lowest-criticality reading first, not the oldest.
  • Benchmarked ONNX Isolation Forest inference at p50 = 2.54ms / p99 = 6.42ms per reading, confirming edge scoring stays within the recovery drain's 5 readings/sec budget.
  • DrainService listens for circuit-breaker CLOSED transitions and rate-limits the recovery drain to 5 readings/sec so live sensor traffic is never blocked; SHA-256 hashing at the edge makes replayed readings dedup-safe against a DB-level unique constraint.
  • Full observability layer — custom Prometheus metrics (buffer depth, circuit-breaker state, dedup count) feeding a live Grafana dashboard, plus PowerShell chaos scripts for demoing kill/recover cycles.
Persistence is currently verified against H2 (PostgreSQL-compatible schema via JPA); TimescaleDB-specific features (hypertables, time_bucket queries) are scoped in docker-compose but not yet independently verified.
